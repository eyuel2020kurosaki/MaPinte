# MaPinte 

## Description

MaPinte est une application web développée avec Vue.js 3 permettant de découvrir, rechercher et explorer des brasseries artisanales à travers le monde grâce à l'API Open Brewery DB.

## Fonctionnalités

- Recherche de brasseries par nom
- Filtrage par type de brasserie
- Filtrage par pays et ville
- Tri des résultats
- Consultation des détails d'une brasserie
- Gestion des favoris
- Brasserie aléatoire
- Affichage de la localisation sur une carte

## Technologies utilisées

- Vue.js 3
- Vue Router
- Pinia
- Axios
- Open Brewery DB API
- HTML / CSS / JavaScript

## Organisation Git

### Branches principales

- `main` : version stable du projet
- `dev` : branche de développement

### Convention de nommage

#### Branches

- `feature/nom-fonctionnalite`
- `fix/nom-correction`
- `docs/nom-documentation`

Exemples :

- `feature/search-bar`
- `feature/favorites`
- `feature/brewery-details`

#### Commits

- `feat: description`
- `fix: description`
- `docs: description`
- `style: description`
